# KGNINJA
Fundamental thinking

This repository is the index for KGNINJA AI-agent-facing public projects. / KGNINJAのAIエージェント向け公開プロジェクトのインデックスです。

## Featured for AI agents / AIエージェント向け

Original public repos that coding agents can discover, run, or load as instructions (MCP, Codex/OpenCode workflows, x402, SKILL.md / AGENTS.md, prompt packs).

### Featured

1. **[HyperXosist-Agent](https://github.com/KG-NINJA/HyperXosist-Agent)** — Agent-first toolkit and Remote MCP server for noise-reduced X search planning, keep-filtering, and Signal-to-Fix handoffs (planning free; production execution via x402).
2. **[Signal-to-Fix](https://github.com/KG-NINJA/Signal-to-Fix)** — Static GitHub Pages app that turns pasted X/Twitter feedback into structured keep/reduce/discard triage and Codex-ready implementation prompts.
3. **[AgentOS-KGNINJA](https://github.com/KG-NINJA/AgentOS-KGNINJA)** — Factory OS: crash-safe queue-driven autonomous build/repair runtime (incoming→leased→done|failed) with Codex repair loops and an x402 machine-payable diagnosis API.
4. **[KG-NINJA-base-sepolia-x402-agent-trade-execution](https://github.com/KG-NINJA/KG-NINJA-base-sepolia-x402-agent-trade-execution)** — Base Sepolia (testnet-only) reference for agents paying x402 v2 API fees then executing user-signed MockUSDC→MockNVDA trade intents with spending limits and evidence v2.
5. **[NINPO](https://github.com/KG-NINJA/NINPO)** — Minimal shell workflow wrapping Codex CLI with git snapshot checkpoints (`nin` to edit, `und` to restore).
6. **[Open-data-agent](https://github.com/KG-NINJA/Open-data-agent)** — Minimal NL→plan→query→summary data-agent POC over CSV/JSON/SQLite with schema-first context and JSONL interaction logs.
7. **[skills.md-](https://github.com/KG-NINJA/skills.md-)** — Single-page HTML form that always emits a valid YAML-frontmatter SKILL.md for Codex / GPT Agent / AGENTS.md workflows.
8. **[psycommu](https://github.com/KG-NINJA/psycommu)** — Session-spanning Markdown instruction templates ("Psyco Markdown Ultimate") to keep project rules consistent across AI sessions.
9. **[GPT-GorinNoSho](https://github.com/KG-NINJA/GPT-GorinNoSho)** — Collection of GPT-5 strategy prompts adapted from OpenAI's official latest-model guidance, presented as a themed "five rings" playbook with 100 ready prompts.
10. **[intent-bridge](https://github.com/KG-NINJA/intent-bridge)** — Static GitHub Pages quiz that turns non-technical answers into structured intent JSON for AI—without writing freeform prompts.
11. **[Noroshi-mk2](https://github.com/KG-NINJA/Noroshi-mk2)** — AI-native public hiring profile (AIEO/NOROSHI) with llms.txt, facts/, evidence/, feeds, and AGENTS.md—built with OpenCode Codex 5.2; no root README.md.

### Honorable mentions

- **[NextPlompter](https://github.com/KG-NINJA/NextPlompter)** — Windows PowerShell helper that finds the Codex window and puts `next` on the clipboard (user still presses Enter).
- **[Codex-RTS-View](https://github.com/KG-NINJA/Codex-RTS-View)** — RTS-style browser visualization of Codex CLI sessions via WebSocket bridge from local session logs (zero pip deps).
- **[headless-markdown](https://github.com/KG-NINJA/headless-markdown)** — Pipeline from OCR/capture Markdown → AI sales-structure transform → HTML landing page (`python main.py`).
- **[HyperXosist](https://github.com/KG-NINJA/HyperXosist)** — Earlier X-search launcher (index.html + AGENTS.md only); description: launcher for Grok and other AI agents searching X. No README.md—prefer HyperXosist-Agent.
- **[n8nOpenHandsmanual](https://github.com/KG-NINJA/n8nOpenHandsmanual)** — Japanese introductory manual for n8n workflow automation (install, UI basics, Docker example).

### 注目リポジトリ

1. **[HyperXosist-Agent](https://github.com/KG-NINJA/HyperXosist-Agent)** — ノイズ低減したX検索プランニング／Keepフィルタ／Signal-to-Fixハンドオフ向けのAgent-firstツールキット兼Remote MCP（計画は無料、本番実行はx402）。
2. **[Signal-to-Fix](https://github.com/KG-NINJA/Signal-to-Fix)** — 貼り付けたXフィードバックをkeep/reduce/discardで仕分けし、Codex向け実装プロンプトを出す静的GitHub Pagesアプリ。
3. **[AgentOS-KGNINJA](https://github.com/KG-NINJA/AgentOS-KGNINJA)** — クラッシュ耐性のあるキュー駆動の自律ビルド／修復ランタイム（Factory OS）。Codex修復ループとx402支払い可能な診断API付き。
4. **[KG-NINJA-base-sepolia-x402-agent-trade-execution](https://github.com/KG-NINJA/KG-NINJA-base-sepolia-x402-agent-trade-execution)** — エージェントがx402 v2でAPI料を支払い、ユーザー署名済みMockUSDC→MockNVDA取引Intentを実行するBase Sepolia専用（テストネット／無価値）参照実装。支出上限とevidence v2付き。
5. **[NINPO](https://github.com/KG-NINJA/NINPO)** — Codex CLIをGitスナップショット付きで使う最小ワークフロー（`nin`で編集、`und`で復元）。
6. **[Open-data-agent](https://github.com/KG-NINJA/Open-data-agent)** — CSV/JSON/SQLiteに対する自然言語→計画→クエリ→要約のデータエージェントPOC。スキーマ優先コンテキストとJSONLログ付き。
7. **[skills.md-](https://github.com/KG-NINJA/skills.md-)** — Codex／GPT Agent／AGENTS.md向けに、壊れないYAMLフロントマター付きSKILL.mdを必ず生成する単一HTMLフォーム。
8. **[psycommu](https://github.com/KG-NINJA/psycommu)** — セッションをまたいでプロジェクト規則を保つMarkdown指示書テンプレート（サイコーミュ／Psyco Markdown Ultimate）。
9. **[GPT-GorinNoSho](https://github.com/KG-NINJA/GPT-GorinNoSho)** — OpenAI公式の最新モデルガイドを元にしたGPT-5戦略プロンプト集。五輪テーマの奥義書形式で実行可能な100忍術を収録。
10. **[intent-bridge](https://github.com/KG-NINJA/intent-bridge)** — 文系ユーザーが質問に答えるだけで、自由記述プロンプトなしにAI向け意図JSONを作る静的GitHub Pagesアプリ。
11. **[Noroshi-mk2](https://github.com/KG-NINJA/Noroshi-mk2)** — llms.txt・facts/・evidence/・フィード・AGENTS.md付きのAIネイティブ公開プロフィール（AIEO/NOROSHI）。OpenCode Codex 5.2で構築。ルートREADME.mdは無し。
